# MUGA — Make USMA Great Again

Landing page académica para el proyecto de Mercadotecnia Internacional de la USMA.

## Estructura

- `index.html` — página principal
- `css/style.css` — diseño y responsive
- `js/script.js` — menú, animaciones y formulario
- `img/` — imágenes que puedes agregar

## Para verla

Abre `index.html` directamente en Google Chrome, Edge o Firefox.

## Imágenes

Puedes colocar:
- `img/hero.jpg`
- `img/experience.jpg`

Si no colocas las imágenes, el sitio seguirá funcionando con los fondos de color definidos en CSS.
